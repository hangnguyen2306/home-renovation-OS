# CLAUDE.md — Renovation OS

## What this is
**Renovation OS** is a commercial Excel workbook for homeowners running a renovation of €50k+.
It tracks budget, quotes, contractors, payments, change orders, timeline (Gantt), rooms,
selections/orders, issues/punch list, documents and warranties. A ranked "next actions" engine
and a health scoreboard sit on top. It is sold as a digital download by Hang Nguyen
(Gumroad is the main channel; Etsy copy also exists).

- **Pro** (16 tabs) and **Lite** (9 tabs: Start Here, Dashboard, Budget, Contractors, Payments,
  Timeline, Issues, plus hidden Engine and Lists). Planned prices: Lite $39, Pro $59.
- Each edition comes as a **DEMO** file (sample project, frozen "today" = 15 Jun 2026) and a **BLANK** file.
- **The workbooks are generated by Python (openpyxl).** Never hand-edit the `.xlsx` files:
  change the generator and rebuild.
- The repo also holds the **marketing kit**: listing images, Pinterest pins, Quick Start PDF,
  lead-magnet PDF, listing copy, social and waitlist plans.

## Hard rules for the workbook
- **100% formulas.** No macros, VBA, scripts, external links, or data connections.
- **Excel 2016 compatible.** No FILTER, SORT, UNIQUE, XLOOKUP, LET, MINIFS/MAXIFS, dynamic arrays,
  TEXT() on dates, or whole-column references. The linter in `ros/core.py` enforces this;
  keep it passing. For a conditional minimum, use `1/SUMPRODUCT(MAX((crit=X)*(1/value)))`-style helpers.
- **Fixed cell map.** All positions live in `ros/layout.py`. Change the constant there,
  never hard-code a cell reference in a sheet builder.
- **Design.**
  - Arial throughout, deep teal accent.
  - **Yellow (`FFF7CC`) = input, and only inputs:** every yellow cell is unlocked and every unlocked
    cell is yellow. Exceptions: merged cells, the legend swatch and hyperlinks.
  - Warnings are orange (`FFEDD5`/`9A3412`), never yellow.
- **Protection** (`harden()`):
  - every sheet protected with a password, formula cells locked and hidden;
  - workbook structure locked;
  - licence line in B3 of every visible sheet and the notice in the footer.
  - The password comes from env `RENOVATION_OS_PASSWORD`, else the gitignored `.protection_password`,
    else a newly generated one. **Never commit or print the password.**
- **Copyright** (option B): `© 2026 Renovation OS — created by Hang Nguyen`. Do not put the
  future BV's name in the files.
- Up to 1000 rows per list tab; Budget has 50 lines.

## Key decisions and why
- **Generated, not hand-built:** reproducible, testable, easy to rebuild for every edition and variant.
- **The Engine uses fixed-offset blocks.**
  - Each source sheet writes hidden helper columns (AlertText, Due, Priority).
  - The Engine stacks them and ranks them with the sort key `Priority*100000+(Due-DATE(2000,1,1))+ROW()/100000`.
  - SMALL/MATCH/INDEX then pick the top 25.
  - This works without dynamic arrays, so it runs in Excel 2016.
- **Timeline predecessors must have a lower ID.** Look-ups only search the rows above, which
  makes circular references impossible.
- **One currency-neutral file set.** Currency, tax label and rate, area unit and week start are
  chosen on Start Here. The USD files were dropped; `--currency USD` still exists for testing.
- **Excel only, no Google Sheets.** Google Sheets strips the protection and hidden formulas.
  Docs mention Sheets only as "not supported".
- **Lite and Pro are separate files.** Lite omits Quotes, Change Orders, Rooms, Selections,
  Document Vault, Warranties and the This Week page. Its demo folds approved change orders into contracts.
  Pro-only features are the upsell.
- **No refunds.** Licence text: "all sales are final". EU consumers keep a 14-day withdrawal right
  unless they explicitly consent to immediate delivery and acknowledge losing it, so the checkout must
  ask for that.
- **Honest limits:**
  - Excel sheet protection can be broken with free tools; it's a deterrent, not DRM.
  - Real Excel has not been tested here, only LibreOffice. Run `EXCEL_CHECKLIST.md` before every release.
